# J.A.R.V.I.S.

Голосовой HUD-ассистент для Windows поверх Claude Code. Вы говорите — Whisper распознаёт речь, простые команды
мгновенно выполняют макросы, всё остальное делает Claude Code на вашем компьютере. Джарвис отвечает записанными
фразами из фильма («Да, сэр», «Запрос выполнен, сэр») и нейроголосом с эффектом «ИИ».

## Запуск

- Ярлык **JARVIS** на рабочем столе (`dist\win-unpacked\JARVIS.exe`), или
- из папки проекта: `npm start`.

**Первый запуск:** CLI Claude Code нужно один раз авторизовать. Нажмите «Авторизовать Claude» на панели
AI CORE (откроется консоль с `claude auth login`) или выполните в терминале:

```
C:\Users\Danny\.local\bin\claude.exe auth login
```

## Управление голосом

| Действие | Как |
|---|---|
| Сказать команду | `Пробел`, клик по реактору или кнопке микрофона |
| Из любого окна | `Ctrl+Shift+Пробел` |
| Остановить речь и задачу | `Esc` или «Стоп» |
| Постоянное прослушивание | кнопка «Режим «Джарвис»» — затем «Джарвис, …» |

Мгновенные команды (без обращения к Claude): «открой юзтайм», «какие у нас проекты», «который час»,
«стоп», «новый разговор», «открой настройки» и все [макросы](#макросы) — «выключи звук», «громкость пятьдесят»,
«поставь таймер на пять минут», «открой калькулятор», «найди в гугле …», «сделай скриншот», «открой заметки».
Всё остальное уходит в Claude Code — с памятью разговора между командами и между запусками.

## Скорость ответов

- **Макросы** отвечают за миллисекунды: ни Claude, ни синтеза речи — только действие и записанная фраза.
- **Тёплое ядро** (Настройки → Ядро, включено по умолчанию): Claude Code запускается заранее и остаётся в памяти
  между командами, команды уходят ему через `--input-format stream-json`. Не тратится время на запуск `claude.exe`
  и загрузку сессии, а «Стоп» прерывает ответ, не убивая процесс. Если установленная версия CLI так не умеет,
  JARVIS сам вернётся к запуску на каждую команду. Через 30 минут тишины процесс освобождает память.
- **Подтверждение фразой**: пока Claude думает над голосовой командой, Джарвис сразу говорит «Есть» или
  «Загружаю, сэр» записанным голосом — пауза не пустая.
- **Кэш голоса**: короткие повторяющиеся фразы синтезируются один раз.
- Ещё быстрее отвечает модель Haiku или Sonnet и «Глубина размышлений: низкая» (Настройки → Ядро).

## Проекты

Список на панели PROJECTS хранится в `%APPDATA%\JARVIS\projects.json`. Добавить проект можно кнопкой «+»,
или Джарвис добавит его сам после деплоя (тег `[[project:Название|URL|Описание]]`).
Клик по карточке открывает сайт внутри HUD (LIVE) или его локальную копию (LOCAL).

## Настройки

- **Голос** — Дмитрий (русский) по умолчанию; тон, скорость, громкость, эффект «ИИ». Сменить голос можно
  и словами: «Джарвис, переключись на George».
- **Слух** — Whisper Small (точнее) / Base / Tiny, язык речи.
- **Ядро** — модель, глубина размышлений, рабочая папка (по умолчанию `D:\`) и права:
  «Правка файлов» разрешает менять файлы, но отклоняет команды терминала; «Авто» и «Полный доступ»
  разрешают больше — включайте осознанно, голосовые команды могут быть распознаны с ошибкой.

### Оригинальный голос Джарвиса

**Фразы Джарвиса** (Настройки → Голос, по умолчанию «Оригинал из фильма»): короткие записанные реплики —
«Да, сэр», «К вашим услугам», «Есть», «Загружаю, сэр», «Запрос выполнен, сэр», «Чего вы пытаетесь добиться, сэр?»,
«Всегда к вашим услугам, сэр», приветствие. Они звучат на имя «Джарвис», при подтверждении команды, после макроса,
на «спасибо» и при запуске — без задержки на синтез. Пакеты взяты из открытого проекта
[Priler/jarvis](https://github.com/Priler/jarvis) (автор Abraham Tugalov, лицензия CC BY-NC-SA 4.0 — только
некоммерческое использование с указанием автора); «Оригинал из фильма» — это нарезка русского дубляжа, права на неё
у правообладателей фильма. Поэтому звуков нет в этом репозитории: JARVIS скачивает выбранный пакет с GitHub при первом
запуске (3,4 МБ) в `%APPDATA%\JARVIS\phrases`. Есть ещё «Ремастер» (приветствия на любое время суток, шутки)
и «Howdy».

**Все ответы голосом из фильма** — голос-клон «Джарвис из фильма»: локальная нейросеть XTTS-v2 копирует тембр
по образцу речи, а образец (≈10 с) JARVIS сам склеивает из оригинальных фраз (`phrases\jarvis-og\reference.wav`).
Нужен Python и, желательно, видеокарта NVIDIA:

```
pip install xtts-api-server
python -m xtts_api_server --device cuda
```

Затем выберите голос «Джарвис из фильма — клон голоса»; адрес сервера — в настройках (по умолчанию
`http://127.0.0.1:8020`). Если сервер не запущен, отвечает Дмитрий «Джарвис», а HUD предупредит об этом.

Ближе всего к Джарвису по манере из готовых голосов — George (британский RP). Британские голоса отвечают по-английски,
а русские фразы озвучивает запасной голос Дмитрий. Офлайн-модели скачиваются при первом выборе
в `%APPDATA%\JARVIS\voices` и работают в отдельном процессе через sherpa-onnx.

## Макросы

Макрос — фраза и действие без участия Claude, как команды в [Priler/jarvis](https://github.com/Priler/jarvis),
только без обязательного AutoHotkey. Готовые наборы лежат в `sandbox\macros\`: звук и громкость, медиаклавиши,
свернуть окна, скриншот, корзина, блокировка, сон, раскладка, буфер обмена, калькулятор, блокнот, проводник,
браузер, поиск в Google и YouTube, Steam и игровой режим, таймер, «спасибо», шутки, «выключись».
Нечёткое сравнение прощает ошибки распознавания, а длинные просьбы остаются Claude.

Свой макрос можно попросить у самого Джарвиса: «Джарвис, сделай команду: когда я говорю „рабочий режим“ —
открой VS Code и почту». Он допишет json в `sandbox\macros`, и команда заработает сразу. Формат и все действия
(программы, клавиши, громкость, PowerShell, AutoHotkey `.ahk`/`.exe`, окна и плагины песочницы) —
в [sandbox\README.md](sandbox/README.md#макросы). Выключить макросы: Настройки → Ядро.

## Песочница: окна и расширения без перезапуска

**Что это простыми словами.** SANDBOX — не отдельный режим и не кнопка: это папка `sandbox\`, в которой Джарвис
(Claude) строит новые возможности для самого себя, пока JARVIS работает. Полоска «SANDBOX» под кнопкой микрофона —
это список окон из этой папки («Заметки», «Таймер»). Сама по себе песочница ничего не делает: она оживает, когда
вы просите Джарвиса что-то сделать или открываете окно из полоски. Разница с обычной работой Claude в том, что
результат появляется сразу внутри HUD, без перезапуска и сборки.

Попросите: «Джарвис, сделай окно со списком покупок», «сделай виджет курса валют», «поставь таймер на пять минут».
Джарвис пишет файлы в `sandbox\`, и они начинают работать сразу:

- **окна** — `sandbox\widgets\<id>\` (HTML/CSS/JS): новое окно открывается само, правки применяются на лету,
  правка CSS — даже без перезагрузки окна; положение и размер запоминаются;
- **плагины** — `sandbox\plugins\<id>.js`: логика на Node.js в отдельном процессе, подменяется при каждой правке;
- **моды HUD** — `sandbox\hud\hud.css` и `hud.js`: дополнения главного окна, тоже на лету.

Окна песочницы видны в доке под кнопкой микрофона: клик — открыть, правый клик — закрыть.
Ошибки окон и плагинов Джарвис видит сам и может их исправить. API и примеры — [sandbox\README.md](sandbox/README.md).

**Если кажется, что песочница не работает:**

- Окна открываются кликом по полоске SANDBOX или голосом: «открой заметки», «поставь таймер на пять минут».
  Правый клик закрывает окно.
- `JARVIS-sandbox.cmd` не включает какой-то особый режим: он запускает тот же живой код, что и `JARVIS.exe`.
  Если JARVIS уже открыт, повторный запуск только поднимает его окно (теперь HUD об этом сообщает).
- Новое окно по просьбе делает Claude, поэтому нужны авторизованный Claude Code и права «Правка файлов» или выше.
  Пока он пишет файлы, в ACTIVITY видны шаги `Write`/`Edit`; окно откроется само, как только появится `index.html`.
- Ошибки окон и плагинов видны в ACTIVITY и в `sandbox\.status.json`; Джарвис получает их со следующей командой
  и может исправить сам («Джарвис, почини окно …»).
- Окно, которое было открыто на отключённом мониторе, теперь открывается на видимом экране.

Правки основного кода тоже применяются сами, когда Джарвис договорил: стили HUD — мгновенно, скрипты
интерфейса — обновлением окна с сохранением журнала, ядро — быстрым перезапуском в то же положение окна
и с теми же открытыми окнами песочницы. `JARVIS.exe` запускает живой код из этой папки (копия внутри
`dist` используется, только если папки проекта нет, или с флагом `--bundled`).

## Где что лежит

- `main.js`, `preload.js` — главный процесс Electron
- `src/brain.js` — мост к `claude -p --output-format stream-json` (тёплое ядро и запуск на каждую команду)
- `src/tts.js` — каталог голосов и синтез: Microsoft Edge (онлайн), Kokoro/Piper (офлайн), XTTS (клон)
- `src/phrases.js`, `renderer/js/phrases.js` — записанные фразы Джарвиса: загрузка, тексты, образец для клона
- `src/macros.js`, `src/rutext.js` — макросы: сопоставление фраз, русские числа и длительности, действия
- `src/winhost.js`, `src/winhost.ps1` — постоянный процесс PowerShell для клавиш, громкости, скриншотов
- `src/voicepacks.js`, `src/tts-offline-host.js` — загрузка офлайн-голосов и их отдельный процесс
- `src/sandbox.js`, `src/plugin-host.js`, `widget-preload.js` — песочница: окна, плагины, API окон
- `src/hotreload.js` — применение правок основного кода на лету
- `src/stt-worker.mjs` — Whisper через transformers.js на CPU (модели в `%APPDATA%\JARVIS\models`)
- `renderer/` — интерфейс HUD
- `%APPDATA%\JARVIS\` — настройки, проекты, журнал `logs\jarvis.log`

Пересобрать `JARVIS.exe` после изменений: `npm run dist`. Тесты макросов, чисел и ядра: `npm test`.

## Диагностика

```
JARVIS.exe --selftest="Джарвис, какие у нас проекты?"
```

Синтезирует фразу голосом, распознаёт её Whisper и выполняет как голосовую команду; результат пишется
в `%APPDATA%\JARVIS\logs\jarvis.log`. `--selftest-text="…"` отправляет текстовую команду в ядро,
`--voice=kokoro:bm_george` пробует голос без изменения настроек, `--profile=<папка>` запускает
отдельный экземпляр рядом с открытым JARVIS, `--selftest-sandbox` проверяет песочницу целиком
(окна, API, плагины, правки на лету, макросы) и убирает за собой.
